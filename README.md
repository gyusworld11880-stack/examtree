# ExamTree

기사시험 문제를 챕터별로 정리하고, **정답만 가린 채 답 개수는 보이는 상태**로 반복 회상 복습하는 iPad용 학습 노트입니다.

- 데이터는 **iPad 안(IndexedDB)에만** 저장됩니다. 서버·계정·구독 없음. 운영비 0원.
- 인터넷이 끊겨도 실행·입력·복습·검색이 모두 됩니다.
- 빌드 도구가 없습니다. 이 폴더의 파일을 그대로 올리면 그게 곧 앱입니다.

---

## 1. iPad에 설치하기

배포 주소(아래 3번에서 만듭니다)를 **Safari**로 엽니다. Chrome이 아니라 Safari여야 합니다.

1. Safari로 `https://<아이디>.github.io/examtree/` 접속
2. 하단(또는 상단)의 **공유** 버튼 →
3. **홈 화면에 추가** →
4. 홈 화면의 ExamTree 아이콘으로 실행

이제 주소창 없이 앱처럼 뜨고, 비행기모드에서도 열립니다.

> 처음 한 번은 온라인 상태로 열어야 앱 파일이 기기에 캐시됩니다.

## 2. 노트북에서 실행/개발하기

```bash
node tools/serve.mjs          # http://localhost:8080
node tools/serve.mjs 3000     # 포트 지정
```

`localhost`는 보안 컨텍스트라 서비스 워커와 IndexedDB가 정상 동작합니다.
같은 와이파이의 iPad에서 노트북 IP로 접속해도 화면은 보이지만, **http라서 오프라인 캐시는 동작하지 않습니다.** 실제 사용은 3번의 https 배포 주소로 하세요.

아이콘을 다시 만들려면:

```bash
node tools/make-icons.mjs
```

## 3. GitHub Pages로 배포하기 (무료)

1. [github.com](https://github.com) 무료 가입
2. **New repository** → 이름 `examtree` → **Public** → *Add a README* 체크 해제 → Create
3. 이 폴더에서:

   ```bash
   git remote add origin https://github.com/<아이디>/examtree.git
   git branch -M main
   git push -u origin main
   ```

   (처음 push할 때 브라우저 로그인 창이 뜹니다.)
4. 저장소 **Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)`** → Save
5. 1~2분 뒤 `https://<아이디>.github.io/examtree/` 접속

### 앱을 수정한 뒤 다시 배포

```bash
git add -A
git commit -m "수정 내용"
git push
```

앱 파일을 바꿨다면 **버전을 두 곳에서 같이 올려야** iPad가 새 버전을 받아옵니다.

- `sw.js` 맨 위의 `VERSION`
- `src/app.js` 의 `APP_VERSION`

iPad에서는 `⋯` → **업데이트 확인** 으로 새 버전을 바로 받을 수 있고, `⋯` → **ExamTree 정보** 에서 지금 실행 중인 버전을 볼 수 있습니다.

## 4. 사용법

### 기본 폴더 구조

처음 실행하면 **건축기사 실기** 폴더 구조(6편 · 32장 · 77절, 폴더 116개)가 자동으로 만들어집니다. 문제는 비어 있으니 공부하면서 채우면 됩니다.

구조를 바꾸고 싶으면 `src/seed-data.js` 를 고치세요. 이미 쓰고 있는 앱에 다시 적용하려면 툴바 `⋯` → **기본 폴더 구조 넣기** 를 누릅니다. **기존 데이터가 전부 지워지므로 먼저 백업하세요.**

### 화면 구성

- **왼쪽**: 폴더 트리. 맨 위 `★ 복습 문제`는 항상 고정입니다.
- **오른쪽**: 표(스프레드시트). 한 줄이 문제 하나입니다.
- 폴더 트리 폭은 가운데 경계선을 드래그해서 조절합니다. 세로 모드에서는 `☰` 버튼으로 여닫습니다.

### 문제 입력

셀을 눌러 바로 입력합니다. **저장 버튼은 없습니다** — 자동 저장됩니다.

| 키 | 동작 |
| --- | --- |
| `Enter` | **셀 안에서 줄바꿈** (서술형 답을 여러 줄로) |
| `Tab` / `Shift+Tab` | 다음 / 이전 칸 |
| `↑` / `↓` | 글 맨 앞·맨 끝에서 누르면 위/아래 행으로 |
| `Esc` | 편집 끝내기 |
| `Cmd+Enter` | 새 문제 추가 |
| `Cmd+B` | 굵게 |
| `Cmd+Z` / `Shift+Cmd+Z` | 실행취소 / 다시실행 |
| `Cmd+F` | 전체 검색 |
| `Cmd+C` / `Cmd+V` / `Cmd+X` | 복사 / 붙여넣기 / 잘라내기 |

- 편집을 끝내려면 오른쪽 아래 파란 **완료** 버튼을 누르거나, 표의 빈 곳을 탭하거나, 마지막 행에서 `Enter`를 누릅니다. iPad 키보드가 내려갑니다.
- 마지막 칸에서 `Tab`을 누르면 새 문제가 자동으로 생깁니다. 계속 이어서 입력할 때 편합니다.
- 답 개수 칸은 숫자만 입력되고, 거기서 `Enter`를 누르면 정답 칸으로 넘어갑니다.
- 글자색의 **기본 (자동)** 은 색 지정을 지웁니다. 라이트/다크 모드에 맞춰 알아서 보이므로, 한쪽 모드에서 글씨가 안 보일 때 쓰세요.

### 행 높이 · 열 너비

- **열 너비**: 표 머리글(`문제`, `정답` 등)의 오른쪽 경계를 좌우로 끕니다.
- **행 높이(전체)**: 툴바 `↕` → `좁게(2줄)` / `보통(5줄)` / `전체`. 답이 길어도 한 화면에 여러 문제가 보이도록 잘라서 보여줍니다.
- **행 높이(개별)**: 행 번호 칸의 **아래 경계**를 위아래로 끌면 그 행만 높이가 바뀝니다. 아주 크게(600px 이상) 늘리면 개별 지정이 해제되고 전체 설정으로 돌아갑니다.
- 잘린 행이라도 **셀을 탭해 편집하는 동안에는 전체가 펼쳐집니다.** 쓰는 글자가 가려지지 않습니다.

### 순서 바꾸기 · 옮기기

- 행 왼쪽의 **번호**를 잡고 끌면 순서가 바뀝니다.
- 번호를 **한 번 탭**하면 그 행이 선택됩니다. (`Shift`+탭으로 범위 선택)
- 행 번호를 잡고 **왼쪽 폴더 위로 끌면** 그 챕터로 이동합니다. 툴바의 `이동` 버튼도 같은 일을 합니다.
- `삭제`와 `이동`은 선택한 행이 없으면 **방금 편집한 행**을 대상으로 삼고, 그 행을 표시해 줍니다.
- 폴더는 오른쪽 `⠿` 손잡이로 끌어서 순서·위치를 바꿉니다. 폴더 가운데에 놓으면 그 폴더의 하위로 들어갑니다.

### 복습하기

1. `복습 모드` 버튼 → 모든 정답이 숨겨집니다. **답 개수는 그대로 보입니다.**
2. 답을 떠올린 뒤 `정답 보기`를 눌러 그 문제만 확인합니다.
3. `전체 가리기` / `전체 보기`로 한 번에 바꿀 수 있습니다.
4. `랜덤`은 화면에 보이는 순서만 섞습니다. 저장된 문제 순서는 그대로입니다.

### ★ 복습 문제

- 다시 볼 문제는 행 맨 왼쪽의 **★**를 누릅니다.
- 왼쪽 맨 위 `★ 복습 문제`를 열면 챕터와 상관없이 ★ 표시한 문제만 한 화면에 모입니다.
- `출처`를 누르면 원래 챕터로 이동하며 해당 행이 잠깐 강조됩니다.
- ★를 다시 누르면 목록에서 빠집니다. **문제 자체는 지워지지 않습니다.**
- 이 화면에서 고친 내용은 원래 챕터에도 즉시 반영됩니다 (사본을 만들지 않고 같은 데이터를 봅니다).

## 5. 백업 — 꼭 읽어 주세요

데이터가 **이 기기 안에만** 있습니다. Safari 데이터를 지우거나 기기를 초기화하면 함께 사라집니다.

- 툴바 `⋯` → **데이터 백업 (JSON 내보내기)** → 파일 앱이나 iCloud Drive에 저장
- 되돌릴 때는 `⋯` → **백업 파일에서 복원**
- 마지막 백업이 14일을 넘기면 `⋯` 버튼에 빨간 점이 표시됩니다.

백업 파일에는 폴더 구조, 문제, 답 개수, 정답, 정답 작성하기, 순서, ★ 표시와 표시 시각, 글자 서식, 컬럼 폭, 설정이 모두 들어갑니다.

## 6. 파일 구조

```
index.html               앱 셸
manifest.webmanifest     PWA 설정
sw.js                    오프라인 캐시 (수정 시 VERSION 올리기)
css/app.css              전체 스타일
icons/                   앱 아이콘
src/
  db.js         IndexedDB 접근
  store.js      메모리 상태 + 저장 + 변경 알림
  undo.js       실행취소 스택
  ui.js         대화상자 · 토스트 · 메뉴 · 드래그 제스처
  tree.js       폴더 트리
  sheet.js      스프레드시트
  review.js     복습 모드 상태 · 랜덤 · 필터
  search.js     전체 검색
  backup.js     JSON 내보내기 / 복원
  toolbar.js    툴바
  app.js        시작 · 화면 전환 · 단축키
tools/
  serve.mjs       개발용 정적 서버 (의존성 없음)
  make-icons.mjs  아이콘 생성기 (의존성 없음)
```

브라우저 콘솔에서 `window.ExamTree`로 내부 상태를 볼 수 있습니다.

## 7. iPad에서 확인할 체크리스트

노트북(헤드리스 브라우저)에서 이미 확인한 항목: 데이터 저장·재실행 후 유지, 오프라인 실행, 정답 가리기/개별 공개/전체 보기, ★ 통합 복습과 출처 이동, 검색, 백업·복원 왕복, 실행취소, 드래그 순서 변경·챕터 이동, 문제 1,200개 성능(챕터 열기 11ms · 검색 8ms).

iPad에서 직접 봐야 하는 항목:

- [ ] Safari에서 열리고 홈 화면에 추가된다
- [ ] 홈 화면 아이콘으로 실행하면 주소창 없이 뜬다
- [ ] 비행기모드에서 실행된다
- [ ] 가로 모드에서 표가 잘리지 않는다
- [ ] 세로 모드에서 `☰`로 폴더 목록이 열린다
- [ ] Magic Keyboard로 `Tab`/`Enter`를 눌러 문제를 연속 입력할 수 있다
- [ ] 손가락으로 행 번호를 끌어 순서를 바꿀 수 있다
- [ ] 셀을 탭하면 화면이 확대되지 않고 바로 입력된다
- [ ] 정답 셀을 탭하면 그 문제의 정답만 나온다
- [ ] 앱을 완전히 껐다 켜도 입력한 내용이 남아 있다
